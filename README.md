# Гранат — изостудия для детей

Адаптивный сайт-прототип изостудии «Гранат» в Авиастроительном районе Казани.

## Что работает
- Адаптивное меню и переходы по разделам страницы.
- Карточки программ с подробностями.
- Галерея иллюстраций, фильтры и просмотр изображения.
- FAQ с раскрывающимися ответами.
- Форма заявки с проверкой обязательных полей и подготовкой текста для копирования.
- Адаптивная мобильная кнопка записи.

## Публикация
Автоматическая публикация настроена через GitHub Actions при push в ветку `main`. Для первого запуска требуется один раз включить Pages в настройках репозитория: Settings → Pages → Build and deployment → Source → GitHub Actions. Затем перезапустите workflow во вкладке Actions.
Публичный адрес после успешного деплоя: https://salakhovkzn.github.io/gpt1/.
URL репозитория: https://github.com/salakhovkzn/gpt1

## Проверить перед запуском для посетителей
1. Указать точный адрес, телефон, расписание, цены и способы записи.
2. Подключить форму к реальному каналу отправки заявок.
3. Заменить демонстрационные иллюстрации галереи реальными работами учеников с необходимыми разрешениями.
4. Добавить согласованный педагогом текст об опыте и образовании Гульнары.
5. Уточнить политику обработки персональных данных и опубликовать необходимые документы.

Сайт собран без фреймворков и внешних библиотек. Основная иллюстрация встроена в HTML; другие изображения отрисованы в SVG.
